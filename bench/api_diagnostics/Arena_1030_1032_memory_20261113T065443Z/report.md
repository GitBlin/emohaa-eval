## 参数

## 结论与限制

评测端配置一致，但当前1032在3个独立会话中均未表现出可用的同会话记忆；1030均成功。历史接口保存消息不代表后台把历史传给底层模型。可能是历史注入、记忆检索开关或提示词约束问题，需要服务端查看最终模型请求才能定位，不能仅凭回复确定根因。

此次测试反映当前状态，不能倒推正式评测时后台配置必然相同。此前Arena成绩可作为两种智能体当时产品状态下的结果；在确认1032历史输入有效之前，不能把分差全部归因于咨询能力。建议检查并对齐两个bot的历史组装配置，复测通过后再运行基线；保留原结果并另开新留档。
